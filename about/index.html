About us

Machinery built in Jining, shipped worldwide

XIAORAN MACHINERY manufactures drilling rigs and compact construction equipment for export buyers who need written specifications, reliable packing and after-sales support.

Company profile

Our workshop in Jining, Shandong assembles exploration rigs, water well rigs, skid steer loaders, spider cranes and aerial work platforms. Machines are built to order: the rod string, pump class, chassis and voltage are confirmed in a written proposal before production starts.

Because we sell factory-direct, buyers deal with the people who build the machine — not an intermediary. That means faster answers on configuration questions, documented run-in testing before packing, and spare parts available from the same source afterwards.

How we work

  1. Application review — depth, formation, site access, power and destination.
  2. Written configuration — model, key components, transport dimensions, price basis.
  3. Build and run-in test — assembly, hydraulic test, machine run before packing.
  4. Packing and loading — container loading documented with photos.
  5. After delivery — wear parts, consumables and technical guidance.
